## Правила и принятые решения

- Открытый сбор показывает текст чужой карточки и её колонку. Имя видно для именной карточки. В закрытом сборе видна одна заглушка на чужую карточку без текста, имени или связи с автором, включая экран фасилитатора. Автор видит свои карточки и может их редактировать при сборе.
- После начала `Group` тексты открываются. В именной встрече отдельную карточку можно создать анонимно. При общей анонимности все карточки анонимны. После завершения удаляются связи с авторами анонимных карточек и записи их создания. Очистка записей создания относится и к карточкам, удалённым при сборе. Анонимность голосов обрабатывается независимо.
- Фасилитатор один. Он может передать роль любому действующему участнику, в том числе офлайн. Присоединение идёт по приглашению после проверки личности. Комментарии остаются видимыми участникам, их записывает фасилитатор. Эмодзи можно вводить как обычный текст.
- Таймер вместе с идентификатором запуска, временем окончания и записями дедупликации живёт только в памяти процесса. После перезапуска старого таймера нет. SignalR передаёт события без текстов карточек и авторства.
- Завершение атомарно сохраняет агрегаты и байты PDF, очищает приватные связи и закрывает приглашение. Ошибка генерации оставляет встречу в `Discuss`. Выдача PDF каждый раз проверяет членство. Изменение статуса Jira после завершения не меняет сохранённый PDF.
- Голосование, группировка и обсуждение работают с темой. Одиночная карточка и группа считаются темами. Поздний участник `Vote` получает полный текущий бюджет.
- SQLite используется для локального MVP. PostgreSQL остаётся целевой СУБД. Приложение рассчитано на один процесс и один pod. Docker на текущей машине отсутствует.
- Внутренний ИИ и Jira используют локальные заглушки без сети. Jira сохраняет идемпотентный `externalRequestId` и умеет отразить неопределённый исход. Корпоративные контракты TWork, Jira, ИИ и Sage пока требуются для итоговой поставки.
