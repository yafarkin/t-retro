# Handoff

Файл содержит актуальный контекст для продолжения работы в новой сессии. Его нужно полностью обновлять по запросу пользователя `сохрани сессию` или `bfe`, а также при любом запросе сохранить контекст перед сменой сессии.

Обновлено 22 ноября 2026 года.

## Как обновлять файл

Перед обновлением нужно проверить фактическое состояние файлов, статусы задач, результаты последних проверок и незавершённую работу. Новый снимок должен содержать текущее состояние, выполненные работы, незавершённую работу, следующие действия, блокировки, принятые решения, результаты проверок и ссылки на все нужные файлы.

При обновлении нужно проверить [спецификацию](Retro_Spec.md), [план](tasks.md), [README](../README.md) и [AGENTS.md](../AGENTS.md) на непротиворечивость, полноту и актуальность. Найденные расхождения нужно исправить или явно записать ниже, если для исправления требуется решение пользователя.

## Текущее состояние

Этап M0 завершён и отмечен в [плане](tasks.md#этап-m0-основа-локального-mvp). Реализованы каркас решения, локальная SQLite-БД, миграции, репозиторий сотрудников, dev-вход, health checks, OpenAPI и основа Angular с Taiga UI. Функциональность встреч ещё не реализована.

Git-репозиторий инициализирован. Первый коммит `e70757f Initial project documentation` содержит документацию. Завершённый M0 зафиксирован отдельным коммитом `Implement M0 application foundation`, рабочее дерево после коммита чистое.

На машине нет Docker. Для локальных проверок используются реальные процессы .NET и Angular, SQLite в файле и npm. Dockerfile и docker-compose можно создать на этапе P3, но не запускать на этой машине.

## Проверки

Последняя полная проверка прошла успешно:

- `dotnet restore TRetro.slnx`, `dotnet build TRetro.slnx --no-restore` и `dotnet test TRetro.slnx --no-build --no-restore`.
- Пройдены 11 backend-тестов: Domain 5, Application 1, Infrastructure 1 и API 4.
- `npm ci`, `npm run build` и `npm test -- --watch=false` прошли без `force` и `legacy-peer-deps`.

- На реальном процессе API проверены миграции, probes, вход двух сотрудников и `/api/me`.
- Через Angular dev-server проверены загрузка страницы, вход через proxy и совпадение ответа `/api/me`.

`npm audit` всё ещё сообщает о четырёх предупреждениях в optional-цепочке `ng-morph` и `minimatch`. npm не предложил безопасного обновления без изменения мажорной версии. Принудительный override не применялся. Открыта задача M10.8 в [плане](tasks.md).

## Принятые решения

- MVP включает полную встречу до `Closed` и PDF. Production-интеграции, PostgreSQL-приёмка, Kubernetes, GitLab CI, Sage и нагрузочный тест относятся к итоговой поставке.
- Временное хранение MVP использует SQLite в локальном файле. Проверки SQLite не заменяют проверки PostgreSQL.
- Таймер будет полностью храниться в памяти процесса, включая `runId` и дедупликацию команд. В БД нельзя сохранять никакие данные таймера.
- Решения и комментарии являются разными сущностями с отдельными хранением, API и выводом в PDF.
- Сотрудник, который вступил во время `Vote`, получает полный текущий бюджет без пересчёта бюджета остальных.
- TWork, Jira, внутренний ИИ и Sage сначала получают порты и dev-адаптеры. Корпоративные контракты нельзя придумывать.
